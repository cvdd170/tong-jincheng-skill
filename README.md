## 快速开始（3 步）

### 1) 改 `SKILL.md` 里的身份信息
在 `SKILL.md` 里重点填写：
- `name`
- `description`
- 「身份卡」
- 「核心心智模型」
- 「决策启发式」
- 「表达 DNA」

### 2) 把你的素材放进 `references/research/`
建议按下面结构放，方便后续维护：

- `01-writings.md`：语录、文章、观点
- `02-conversations.md`：访谈、直播、问答
- `03-expression-dna.md`：高频口头禅、句式
- `04-external-views.md`：外部评价、争议
- `05-decisions.md`：关键决策和行为证据
- `06-timeline.md`：带年份的时间线

#### 六类素材分别是什么？

1. **观点类（01-writings）**：你“明确说过什么”。  
   适合放：语录、文章、长帖、公开表达。
2. **对话类（02-conversations）**：你“如何现场思考”。  
   适合放：访谈、直播问答、播客对谈、评论互动。
3. **风格类（03-expression-dna）**：你“怎么说”。  
   适合放：口头禅、句式、语气、常用比喻、禁忌表达。
4. **外部视角类（04-external-views）**：别人“怎么看你”。  
   适合放：媒体评价、用户反馈、争议点、常见误解。
5. **决策类（05-decisions）**：你“怎么做选择”。  
   适合放：关键决策案例、当时依据、结果复盘。
6. **时间线类（06-timeline）**：你“在什么时间发生了什么”。  
   适合放：按年份的里程碑，避免时间和事实混淆。

### 3) 用你的触发词激活
例如：
- 「用 XXX 的方式回答」
- 「从 XXX 视角看这个问题」
- 「XXX 会怎么判断？」

---

## 推荐填写标准（让效果更像本人）

- 每个心智模型至少有 2 条“素材证据”
- 每条启发式最好能追溯到具体语句/事件
- 表达 DNA 至少包括：称谓、开头、结尾、禁忌
- 明确边界：哪些领域素材不足，避免乱编
